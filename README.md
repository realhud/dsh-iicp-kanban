# dsh-iicp-kanban

DSH 一体化智能协作平台插件：四列看板 + 项目分组 + **一个队长 Agent 带领多个工作 Agent**（派单 / 提交 / 验收）+ **AI AGENT 执行语义**（目标联动/子任务进度推导/交付物/字段锁定）。基于 dsh-super-kanban 的架构模式（零构建、零依赖）全新实现，任务数据模型与其 v2 契约对齐，单机本地存储。

- 使用说明：[docs/manual.md](docs/manual.md)
- 架构设计：[docs/architecture.md](docs/architecture.md)
- 领域模型：[docs/domain.md](docs/domain.md)
- 接口契约：[docs/api.md](docs/api.md)
- 界面设计：[docs/ui.md](docs/ui.md)
- 验收清单：[docs/verify.md](docs/verify.md)

## 快速开始

```powershell
npm test   # node --test --test-isolation=none → 73 用例
```

安装到 DSH 后打开 Web 界面即见「一体化智能协作平台」；健康检查 `GET /iicp-kanban/api/ping`。

## 能力一览

| 能力 | 说明 |
| --- | --- |
| 四列看板 | 待办/进行中/受阻/已完成，拖拽改状态，写任务历史 |
| 队长 + 工作成员 (v0.3) | 成员类型 `lead`/`worker` + 归属队长 + 人格/技能/提供方/模型/状态；第一个成员自动成为队长，一队只有一个队长 |
| 模型目录选择 (v0.4) | 成员的提供方/模型从 DSH 现有的 `llm` 目录里选（`GET /models`，弹窗打开时取一次）；默认「继承工作区」= 跟随宿主默认模型，不写死 id |
| 派单 / 提交 / 验收 (v0.3) | 队长派单（backlog→进行中）、工作成员提交（进「待验收」，**状态列不动**）、队长验收（通过→完成 / 返工→进行中）；**做的人不能验收自己的活**，规则挡在服务端 |
| 团队视图 (v0.3) | 队长卡（`N 门下` + 人格 + 技能 + 待验收/进行中/受阻/未指派四项指标）+ 待验收队列 + 工作成员卡片网格 + 全员明细表 |
| 任务指派 | 任务↔成员引用完整性校验；改派/删成员写历史 |
| 项目分组 | 项目 CRUD；删项目任务自动脱钩 |
| 项目模块 (v2.6) | 卡片网格 + 「工作区项目（按 DSH 工作区自动生成）/ 自建项目（跨工作区）/ 已归档项目(N)」三段；卡片含指标行（近期完成·受阻·逾期·进行中）+ 进度条 + 到期日 + 备注；项目 `dueDate`（严格 YYYY-MM-DD）/ `workspaceId` / notes ≤600；归档项目拒收新任务；卡片「看板」切回看板并带入范围过滤 |
| AI AGENT 语义 (v2) | goal 对象随状态联动、验收标准、子任务（≤12，进度自动推导）、交付物（≤10）、lockedFields 字段保护、origin:"session" 会话挂靠；拖到「已完成」自动关闭生成子任务 |
| 到期日 (v2.1) | 任务到期日（YYYY-MM-DD）；卡片 📅 pill，过期未完成红色高亮；新建表单对齐 dsh-super-kanban（折叠规划区/seg 状态与优先级/Enter 提交/saving 态） |
| 任务卡片 (v2.3) | v3 卡片：状态圆点 + 相对时间 + 优先级/指派/交付物/子任务指标 + 摘要行 + 进度条；已完成态收敛 |
| 任务详情抽屉 (v2.4) | **单击卡片**从右侧滑出详情抽屉（概览/子任务/交付物/变更历史），**双击仍是编辑弹窗**；Esc/遮罩/返回关闭，「打开编辑」直达弹窗 |
| 看板交互对齐 (v2.5) | 页头统计行 + 搜索框、slimbar（视图分段/项目/指派/可见计数/筛选浮层：优先级·来源·标签·含归档）、卡片更多菜单（置顶/归档/移至/删除）、列头「+」与已完成列折叠、30 条分页、置顶排序与徽章、乐观更新 + toast、`/`·`n`·`Esc` 快捷键、骨架加载与错误重试 |
| 工作区发现 | 只读 DSH workspace.json（优先 `tables.workspaces` 现行布局），看板内管理纳入标志 |
| 安全 | owner-only（fail-closed），数据本地 `$DSH_HOME/storages/iicp-kanban/state.json` |
